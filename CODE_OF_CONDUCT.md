# Code Of Conduct

AgoraMesh is built around voluntary association, non-violence, and consent.

Participants are expected to:

- Treat others with basic respect.
- Avoid harassment, threats, coercion, and doxxing.
- Respect boundaries and voluntary participation.
- Disclose conflicts of interest when mediating.
- Keep discussions focused on improving the project.

The project does not welcome contributions or usage patterns that promote violence, fraud, exploitation, stolen goods, harassment, or non-consensual activity.

Maintainers may remove issues, pull requests, or participation that conflicts with these principles.
